# P05 测试与验收清单

状态：以下行为测试均未执行。当前机器没有 TIA Portal、PLCSIM 或现场设备；源文件结构检查不能代替编译与功能测试。

| 编号 | 输入/操作 | 预期检查 |
|---|---|---|
| 01 | 两份源文件导入目标 TIA 工程 | 类型/FB 生成并编译通过；检查目标 CPU 支持的数据类型、MIN 调用等 |
| 02 | Reviewed=FALSE，或周期/超时不合法 | CommandValid=FALSE，不发设备写入 |
| 03 | 停止证明与运行证明同时为 TRUE | 禁止新写入，提示数据/协调问题 |
| 04 | 全停初始化，需求从 0 改为 2 | 先等待最小停机/阶段间隔，选运行小时最少一台；第一台制冷证明后再加第二台 |
| 05 | 第一台尚在启动，再次扫描同一需求 | 启动中台数计入承诺容量，不重复投机 |
| 06 | 两台运行小时相同 | 选编号小者，结果可重复 |
| 07 | 需求 3 降为 2 | 满足最小运行时间后，选小时最多自动机组有序停机 |
| 08 | Enable=FALSE 且 DemandValid=TRUE | 逐台正常减至零，仍满足最小运行时间与后循环；不是急停 |
| 09 | 启动中阀路不到位 | 不启泵；超时锁故障，进入有序停止流程 |
| 10 | 泵启动无运行反馈 | 不发冷机启动；超时锁故障 |
| 11 | 水流证明断续，未连续达到时限 | 不启冷机；连续证明计时清零；总阶段超时后故障 |
| 12 | 冷机启动超时 | 同扫描撤销冷机请求，保留有序停止水路/泵处理 |
| 13 | 正常运行后水流/泵/水路/冷机反馈丢失 | 锁故障，撤销冷机请求，按已定义停止流程处理；独立保护优先 |
| 14 | 冷机停止反馈始终不到 | 泵与水路不因超时而强关；SequenceBlocked 报警；不假装已停机 |
| 15 | 冷机已停、泵后循环结束 | 先停泵并确认，再请求关闭停止水路并确认 |
| 16 | 某台启动失败后完全停机 | 故障机不重复投；阶段间隔满足后选下一台；记录实际恢复时间 |
| 17 | 故障机停机未完成 | 本稿阻止后续增机；验证此限制是否违反项目恢复指标 |
| 18 | 全部可用机组均无资格 | NoStartCandidate；有效供冷不足时 DemandShortfall；不得强启故障机 |
| 19 | 通信失效/控制权丢失/需求无效 | 禁止写新命令，接口层保持上次有效请求并执行独立超时/回退，不把默认零当有效命令 |
| 20 | 手动运行或手自动切换 | 手动机组无群控写入；有效供冷计数；切换后重新协调初始化 |
| 21 | 故障仍在时复位，或复位位长按 | 故障不错误清除；仅健康完全停止时上升沿清除 |
| 22 | 冷启动、运行中掉电或冗余接管 | 全停初始化验证；运行中单机恢复应明确阻止并要求协调，不得宣称无扰切换 |
| 23 | 未安装单元、3 台配置、5 台配置 | 未安装单元不参与；数量边界正确；配置变更需计划停机/受控接管 |
| 24 | 需求越界、运行小时非法 | 禁止调度；修复输入来源，不强行夹紧错误数据 |
| 25 | 实际设备协议对接 | 验证起停脉冲/维持命令、超时、寄存器地址、缩放、端序、反馈极性及质量 |
| 26 | 设计负荷阶跃与单机故障 | 在 PLCSIM/联调中确认允许温升、恢复时间、最大并行台数和压差波动；本稿尚无此性能结论 |

通过 01 后才能称为目标版本可编译；通过代表性模拟场景后才能称为模拟功能已验证；现场 FAT/SAT 和保护确认后才能评估上线。
